# Развёртывание приложения

## Использованные абстракции Kubernetes

- **Namespace** — `medtracker` для изоляции ресурсов приложения.
- **ConfigMap** — хранение конфигурации приложения.
- **Secret** — хранение пароля PostgreSQL и JWT-секрета.
- **Deployment** — запуск frontend и backend.
- **StatefulSet** — запуск PostgreSQL.
- **PersistentVolumeClaim (PVC)** — постоянное хранение данных PostgreSQL.
- **Service** — доступ к frontend и backend внутри кластера.
- **Headless Service** — доступ к PostgreSQL внутри кластера.
- **Ingress** — маршрутизация входящих HTTP-запросов к frontend и backend.

## Взаимодействие сервисов

Входящие HTTP-запросы маршрутизируются через Ingress:

- `/api/*` → `medtracker-backend:8080`
- `/*` → `medtracker-front:80`

Frontend и backend доступны через соответствующие Kubernetes Service.

Backend подключается к PostgreSQL по внутреннему DNS-имени `postgres:5432`.
